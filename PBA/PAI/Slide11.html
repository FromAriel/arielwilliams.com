Text transcript

1. Made With AI (Construction)

  • Developer Tooling: LLM assists in generating source code, SQL schemas, and test suites.
  • Execution Boundary: AI interaction ends when development completes.
  • Client Privacy: No client matter or live document is ever transmitted during construction.
  • Result: Standard, compiled software running deterministically on local infrastructure.

2. Powered By AI (Runtime)

  • Continuous Inference: Application depends on live API calls to third-party cloud models.
  • Confidentiality Risk: Client files, transcripts, or notes are uploaded across the wire.
  • Model Drift & Cost: Non-deterministic outputs, API rate limits, and latency variances.
  • Result: Requires vendor data agreements, security audits, and client disclosures.

"Made with AI" tells you nothing about data flow. Demand to know where case documents travel during operation.
